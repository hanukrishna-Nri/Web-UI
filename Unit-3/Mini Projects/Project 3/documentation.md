# **Project Title**

**College Event Management Interface**

---

# **Project Overview**

The College Event Management Interface is a responsive website developed using **HTML5 and CSS3**. It provides an easy way for students to view upcoming college events, event schedules, registration information, and contact details. The website focuses on creating a simple, attractive, and user-friendly experience without using JavaScript.

---

# **Problem Statement**

Design a complete user experience for organizing and managing college events.

---

# **Objectives**

* Design a responsive and attractive website.
* Display college event information clearly.
* Provide an online event registration form.
* Show event schedules and venue details.
* Create a user-friendly navigation system.
* Improve the overall user experience.

---

# **Features**

* Responsive homepage
* Navigation bar
* Event information section
* Event registration form (HTML only)
* Event schedule section
* Gallery section
* About section
* Contact section
* Responsive layout for mobile and desktop
* Attractive color theme
* Hover effects using CSS

# **Installation and Setup**

1. Install Visual Studio Code.
2. Create a project folder.
3. Add the following files:

   * index.html
   * style.css
4. Create an **images** folder.
5. Place all required images inside the images folder.
6. Open the project folder in Visual Studio Code.
7. Open **index.html** in any web browser.

---

# **How to Run the Project**

1. Open Visual Studio Code.
2. Open the project folder.
3. Double-click **index.html** or use **Live Server**.
4. The website will open in Google Chrome.
