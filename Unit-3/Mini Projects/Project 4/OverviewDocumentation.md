# Mini Project 04: Blood Donor Management Application

## Project Overview

The **Blood Donor Management Application** is a simple web-based user interface that connects blood donors with people who need blood during emergencies. The main objective of this project is to design an easy-to-use and visually appealing interface where users can view available services and register as blood donors.

This project focuses on **User Interface (UI)** and **User Experience (UX)** design principles rather than database connectivity or backend development. It demonstrates how to organize information clearly, create user-friendly forms, and build a responsive webpage that works on both desktop and mobile devices.

---

# Problem Statement

Design an intuitive interface that connects blood donors and recipients by providing a simple platform for donor registration, blood donor search, emergency support, and blood bank information.

---

# Project Objectives

* Create a clean and attractive user interface.
* Make the website easy to navigate.
* Provide a simple donor registration form.
* Display important blood donation services.
* Ensure the website is responsive and accessible.

---

# Features of the Application

* Home page with project title.
* Navigation menu for easy access.
* Service cards displaying available services.
* Donor registration form.
* Emergency contact information.
* Responsive layout for mobile and desktop devices.

---

# Technologies Used

* HTML5

  * Used to create the structure of the webpage.
  * Includes headings, paragraphs, forms, navigation menu, and footer.

* CSS3

  * Used to design the webpage.
  * Adds colors, spacing, borders, fonts, and responsive layout.

# User Interface Components

The application contains the following sections:

1. Header

   * Displays the application name and purpose.

2. Navigation Bar

   * Provides links to different sections of the application.

3. Welcome Section

   * Gives a brief introduction to the application.

4. Service Section

   * Displays major services such as:

     * Register Donor
     * Find Donor
     * Blood Banks
     * Emergency Help

5. Registration Form

   * Allows donors to enter their basic details.

6. Footer

   * Displays emergency helpline and contact information.

---

# Color Theme

The application uses a healthcare-inspired color scheme.

* Red – Represents blood donation and emergency services.
* White – Provides a clean and simple appearance.
* Light Gray – Used as the background for better readability.

---

# Typography

The project uses a simple and readable font (Arial) to improve readability for all users.

---

# Accessibility Features

The application includes basic accessibility features such as:

* Clear headings
* Proper labels for form fields
* Easy-to-read font size
* Good color contrast
* Large buttons
* Responsive layout

---

# Responsive Design

The webpage automatically adjusts its layout for different screen sizes.

* Desktop View

  * Service cards are displayed side by side.

* Mobile View

  * Service cards are displayed one below another.
  * Navigation links are arranged vertically.

---

# Folder Structure

The project contains two files:

* index.html
* style.css

Both files should be saved in the same project folder.

---

# Implementation Steps

1. Create a new project folder.
2. Create the HTML file.
3. Create the CSS file.
4. Save both files in the same folder.
5. Open the HTML file in a web browser.
6. Verify that the page loads correctly.
7. Test the webpage on different screen sizes.
