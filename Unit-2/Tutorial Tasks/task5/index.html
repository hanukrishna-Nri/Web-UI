Understanding Content, Padding, Border and Margin

Content Area

This is the content area of the box. It contains the actual text or image displayed inside the element.

Padding

Padding is the space between the content and the border.

Border

The border surrounds the padding and content. It defines the visible boundary of the element.

Margin

Margin is the space outside the border that separates elements from each other.
