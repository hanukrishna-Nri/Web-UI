# Project Title

**Mini Project 3: E-Commerce Product Showcase**

---

## Project Overview

The **E-Commerce Product Showcase** is a responsive web application designed using **HTML5** and **Inline CSS**. It displays different product categories along with product cards containing images, names, prices, and a "Buy Now" button. The project demonstrates responsive web design concepts and provides a simple user interface similar to an online shopping website.

---

## Problem Statement

**Create a responsive e-commerce website interface displaying products and categories.**

---

## Objectives

* Design a responsive e-commerce webpage.
* Display multiple product categories.
* Showcase products with images, names, and prices.
* Create an attractive and user-friendly interface.
* Demonstrate responsive layout using HTML and Inline CSS.

---

* Responsive webpage layout

## Installation and Setup

1. Install Visual Studio Code.
2. Create a folder named **MiniProject3**.
3. Create an **images** folder inside the project.
4. Add the product images:

   * image1.jpg
   * image2.jpg
   * image3.jpg
5. Save the HTML file as **index.html**.
6. Open the project folder in Visual Studio Code.

---

## How to Run the Project

1. Open the project folder.
2. Open **index.html**.
3. Run using **Live Server** or open the file directly in a web browser.
4. The E-Commerce Product Showcase webpage will be displayed.
